# Test Plan – Manual QA Testing

## Test Objective
Manuelle Validierung von REQ-01 bis REQ-04 sowie explorative Untersuchung nicht spezifizierter Verhaltensweisen.

## Scope
Login, Product Catalogue, Shopping Cart, Checkout, Pflichtfeldvalidierung, Counter, Bestellabschluss, explorative Eingabe- und Navigationsfälle.

## Out of Scope
Payment-Systeme, Backend/API, Performance, Security/Penetration, Automation, Registrierung, Passwort-Reset.

## Test Types
Functional Testing, Negative Testing, Exploratory Testing, UI/Usability observations.

## Environment
- SauceDemo / Swag Labs
- https://www.saucedemo.com/
- Windows (Version nicht aufgezeichnet)
- Google Chrome (Version nicht aufgezeichnet)
- PC
- standard_user / secret_sauce

## Entry Criteria
Anwendung erreichbar; Testaccount verfügbar; Requirements analysiert; Test Cases vorbereitet.

## Exit Criteria
Alle formalen Tests ausgeführt; explorative Sessions abgeschlossen oder nachvollziehbar blockiert; Ergebnisse dokumentiert; Defects ggf. erfasst; Summary erstellt.

## Risks / Open Issues
Unvollständige Akzeptanzkriterien; nicht protokollierte Browser-/OS-Version; fehlende Testdaten für nicht verfügbare Produkte; Observations ohne definierte Expected Results.
