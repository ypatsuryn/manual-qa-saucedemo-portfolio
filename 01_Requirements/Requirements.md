# Requirements – Manual QA Practice Project

## REQ-01 – Login

Ein registrierter Benutzer kann sich mit gültigem Benutzernamen und Passwort anmelden. Bei ungültigen Login-Daten wird eine Fehlermeldung angezeigt. Benutzername und Passwort sind Pflichtfelder.

## REQ-02 – Product Catalogue

Nach erfolgreichem Login sieht der Benutzer eine Liste verfügbarer Produkte. Jedes Produkt enthält mindestens Produktname, Beschreibung und Preis.

## REQ-03 – Shopping Cart

Ein Benutzer kann Produkte zum Warenkorb hinzufügen. Ein Benutzer kann Produkte wieder entfernen. Der Warenkorb zeigt die Anzahl der hinzugefügten Produkte.

## REQ-04 – Checkout

Ein Benutzer kann vom Warenkorb zum Checkout wechseln. First Name, Last Name und Postal Code sind Pflichtfelder. Bei fehlenden Pflichtangaben soll eine Fehlermeldung erscheinen. Bei gültigen Angaben kann der Benutzer die Bestellung abschließen. Nach erfolgreicher Bestellung wird eine Bestätigung angezeigt.
