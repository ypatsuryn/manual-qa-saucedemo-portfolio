# Lebenslauf-Eintrag – QA-Praxisprojekt

**Manual QA Testing – E-Commerce Web Application (Praxisprojekt)**

- Manuelle Tests einer E-Commerce-Webanwendung (Login, Product Catalogue, Warenkorb, Checkout) auf Basis definierter Requirements geplant und durchgeführt.
- 23 funktionale/negative Test Cases erstellt und ausgeführt; Expected vs. Actual Results sowie Pass/Fail dokumentiert.
- 27 explorative Tests geplant und nicht spezifizierte Verhaltensweisen systematisch dokumentiert.
- Requirement-Lücken analysiert und 29 Clarification Questions zu Validierung, Eingabegrenzen und Navigation formuliert.
- Test Plan, Test Execution Summary und Test Summary Report erstellt; auffälliges Verhalten von bestätigten Defects abgegrenzt.
