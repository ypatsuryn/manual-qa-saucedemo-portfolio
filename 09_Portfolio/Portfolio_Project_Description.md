# Portfolio Project Description

## Manual QA Testing – E-Commerce Web Application

**Application:** SauceDemo / Swag Labs  
**Project type:** Self-initiated QA practice project  
**Role:** Manual QA Tester  
**Scope:** Login, Product Catalogue, Shopping Cart, Checkout

### Responsibilities
- Analysed four functional requirements and identified test conditions.
- Designed and executed 23 requirement-based manual test cases.
- Planned 27 exploratory test scenarios across input handling, navigation, product catalogue, cart and checkout behavior.
- Documented 29 requirement clarifications for unspecified behavior and missing acceptance criteria.
- Compared expected and actual results and assigned Pass/Fail status based on requirements.
- Evaluated unusual behavior separately from confirmed defects.
- Produced a test plan, execution summary and final test summary report.

### Outcome
All 23 formal test cases passed. One exploratory scenario was not testable because suitable test data was unavailable. No confirmed defects were identified under the simplified practice requirements.
