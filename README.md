# Manual QA Testing Portfolio – SauceDemo

## Project Overview
This repository documents a self-initiated manual QA practice project for the SauceDemo / Swag Labs web application.

The project demonstrates a complete lightweight QA workflow: requirement analysis, test design, manual test execution, exploratory testing, requirement clarification, result reporting, and defect evaluation.

## Scope
The practice specification contains four requirements:
- REQ-01 – Login
- REQ-02 – Product Catalogue
- REQ-03 – Shopping Cart
- REQ-04 – Checkout

## Test Approach
- Functional testing
- Negative testing
- Exploratory testing
- Requirement-based testing
- Basic UI/usability observations
- Manual regression-style rechecks during execution

## Key Learning Outcomes
- Derived test cases from explicit requirements without inventing expected behavior.
- Distinguished negative test success from test-case failure.
- Separated requirement-based tests from exploratory test ideas.
- Documented observations that looked unusual without incorrectly classifying them as defects.
- Identified missing acceptance criteria and recorded them as requirement clarifications.
- Produced test plan and test summary reporting for a complete manual test cycle.
